# Customer Segmentation

## Project Overview

This project performs customer segmentation using the Online Retail dataset.
The analysis uses RFM (Recency, Frequency, Monetary) analysis and K-Means clustering to identify different groups of customers.

## Objectives

- Analyze customer purchasing behavior
- Calculate Recency, Frequency, and Monetary values
- Apply data preprocessing and feature scaling
- Determine the suitable number of customer clusters
- Segment customers using K-Means clustering
- Profile the identified customer groups
- Develop marketing strategies for each segment

## Analysis Performed

- Data loading and inspection
- Data cleaning and preprocessing
- Descriptive statistics
- Customer purchase analysis
- Average purchase value and purchase frequency
- Customer lifetime value analysis
- RFM feature creation
- Feature scaling using StandardScaler
- Elbow Method for selecting the number of clusters
- K-Means clustering
- Cluster visualization and profiling
- Customer count analysis
- Marketing recommendations

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Key Outcome

The project identifies distinct customer segments based on their purchasing behavior and provides targeted marketing recommendations for each customer group.
