# EDA Retail Sales

## Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data to understand sales performance,
customer patterns, product performance, and relationships between numerical variables.

## Objectives

- Understand the structure and quality of the dataset
- Analyze monthly and quarterly sales trends
- Study customer age and gender distribution
- Identify top-performing products
- Analyze revenue by product category
- Study correlations between numerical variables
- Generate useful business insights and recommendations

## Analysis Performed

- Data loading and inspection
- Data type and missing value analysis
- Descriptive statistics
- Monthly and quarterly sales analysis
- Customer age-group analysis
- Gender-wise analysis
- Top 10 product analysis
- Revenue by product category
- Correlation analysis
- Additional sales and profit visualizations

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Outcome

The analysis provides insights into sales trends, customer characteristics, product performance, revenue contribution,
and profitability to support data-driven business decisions.
